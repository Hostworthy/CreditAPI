      App setup
      1. In your app's AI settings, add a provider of type OpenAI or OpenAI compatible.
      2. Base URL: the value above. Most apps want it to end in /v1.
      3. API key: a virtual key created here.
      4. Model: one of the models listed above. To use one particular subscription, put its short name in front, like claude-personal/sonnet. Other model names use each subscription's default model.
      5. If the app runs in Docker on the same host, use this container's name in the base URL. Some apps only allow private-network addresses after you enable that in their settings.
